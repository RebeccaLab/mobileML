# Deepfake dataset inventory

This repository documents the pre-labeled deepfake data gathered for the
mobile-model compression study. The raw videos and extracted frames are not
stored in GitHub. They remain on the lab workstation (`linlab2`) because the
prepared copies are too large for a normal repository and may have
access/redistribution restrictions.

## Storage policy

The current prepared data is stored under the following project root on
`linlab2`:

```text
/home/pcl/Deepfake-Detection
```

That path is the local lab storage location, not a path that must exist in a
fresh checkout of this repository. This document records the verified paths,
counts, labels, provenance, and access notes.

## Label convention

For the benchmark study, labels are normalized as:

```text
0 = real/original
1 = fake/manipulated
```

The source datasets do not all use the same class names or raw label values.
The mappings below must be applied before combining results.

## Datasets

### FaceForensics++ (FF++)

FF++ contains original source videos and manipulated versions generated by
multiple face-manipulation methods. The prepared copy contains:

- `Original` — real, label `0`
- `Deepfakes`, `Face2Face`, `FaceSwap`, `NeuralTextures`, and `FaceShifter` —
  fake, label `1`

The project follows the standard video-level split of 720 training, 140
validation, and 140 test videos. The prepared face-frame inventory is:

| Split | Real frames | Fake frames | Total |
| --- | ---: | ---: | ---: |
| Training | 21,600 | 21,600 | 43,200 |
| Validation | 4,200 | 4,200 | 8,400 |
| Test | 4,200 | 4,200 | 8,400 |

Local prepared data:

```text
/home/pcl/Deepfake-Detection/prepared_dataset
```

FF++ is the primary training dataset and the in-domain baseline test set.
Official project: <https://github.com/ondyari/faceforensics>.

### Celeb-DF++

Celeb-DF++ is a newer external generalization benchmark, not the older
Celeb-DF v2 dataset. The lab copy extracts its test videos under the root
directory `Celeb-DF-v3`. It contains 22 fake methods in three scenarios:

- 8 face-swap methods
- 7 face-reenactment methods
- 7 talking-face methods

The prepared test manifest contains 5,418 videos:

```text
178 real videos
5,240 fake videos
```

Local prepared data and manifest:

```text
/home/pcl/Deepfake-Detection/external_data/celeb_df_pp/test_videos
/home/pcl/Deepfake-Detection/external_data/celeb_df_pp/test_videos/test_manifest.jsonl
```

The archive recorded by the preparation marker is `Celeb-DF++.zip`. The
nested `FaceSwap/Celeb-DF-v2` directory is only one source/method subset
inside the larger Celeb-DF++ benchmark; it does not change the identity of
the overall dataset to Celeb-DF v2.

Celeb-DF++ is used as an external test set. Its paper describes the three
scenarios and 22 methods: <https://arxiv.org/abs/2507.18015>.

### DF40

DF40 is a collection of 40 distinct deepfake generation techniques. It is not
simply another copy of FF++ or Celeb-DF. Each method has its own fake-data
archive and official JSON manifests. The methods are grouped into:

- 10 face-swapping methods
- 13 face-reenactment methods
- 12 entire-face-synthesis methods
- 5 face-editing methods

For 31 known methods, DF40 generates fake data from FF++ or Celeb-DF source
domains. The official manifests use `ff` and `cdf` to identify those source
domains. The remaining 9 unknown-domain methods package their own real data:

```text
FF++/Celeb-DF source domain + new DF40 generator = cross-manipulation test
new source domain + new generator                  = stronger cross-domain test
```

“Unknown” means that the source domain/generation setting is unseen relative
to the FF++/Celeb-DF training domain. It does not mean that the files are
missing labels or are unrecognized. The nine test-only methods are:

| Method | Broad type | Real-data source in DF40 |
| --- | --- | --- |
| DeepFaceLab | Face swapping | UADFV |
| HeyGen | Face reenactment | FFHQ |
| MidJourney-6 | Entire-face synthesis | FFHQ |
| WhichIsReal | Entire-face synthesis | FFHQ |
| CollabDiff | Face editing | CelebA |
| e4e | Face editing | CelebA |
| StarGAN | Face editing | CelebA |
| StarGANv2 | Face editing | CelebA |
| StyleCLIP | Face editing | CelebA |

## Evaluation protocol

The intended benchmark sequence is:

1. Train the uncompressed baseline on the FF++ training split.
2. Select settings using the FF++ validation split.
3. Compare the uncompressed and compressed models on the held-out FF++ test
   split.
4. Evaluate both models without fine-tuning on Celeb-DF++ and DF40.
5. Report accuracy with the class counts and label mapping used for each
   dataset. Per-method and per-source-domain results should be retained for
   DF40.

The external test sets should not be used for training or compression tuning
when reporting cross-dataset generalization. Because the external datasets are
not class-balanced, accuracy should be accompanied by per-class results or
balanced accuracy where possible.

## Access and reproducibility

This repository records where the gathered copies are stored and how they are
labeled; it does not redistribute the raw datasets. Anyone reproducing the
study must obtain the source datasets under the respective authors' access and
use terms, then place the prepared copies at the documented lab paths.
